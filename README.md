# Проект "Виджет банковских операций"

## Описание:

Серверная часть виджета банковских операций для личного кабинета клиента:
* Маскировка номеров счетов и карт при выводе последних банковских операций.
* Вывод дат операций в стандартной форме.
* Фильтрация операций по статусу.
* Сортировка операций по дате.
* Генераторы для работы с транзакциями:
  * Фильтрация по валюте.
  * Формирование описаний операций.
  * Генерация номеров карт.
* Конвертация валют:
  * Перевод сумм в рубли через API из USD и EUR.
* Логирование вызовов функций:
  * Автоматическая регистрация деталей выполнения функций в консоль и в файл:
    * Время вызова, имя, аргументы, результат или ошибку.
* Поддержка форматов данных JSON, CSV и Excel (*.xlsx, *.xls):
  * Автоматическое распознание расширений и загрузка транзакций.
* Фильтрация, сортировка и поиск транзакций из файла по поддерживаемым форматам:
  * Фильтры и отборы:
    * по статусу транзакций;
    * по RUB-валюте;
    * по ключевому слову.
  * Сортировка по датам:
    * по убыванию (от новых к старым);
    * по возрастанию (от старых к новым).

## Тестирование функций:

### [test_masks](tests/test_masks.py) для [masks](src/masks.py)
`get_mask_card_number` и `get_mask_account`

Маскировки:
* Стандартный ввод;
* Нестандартный ввод;
* Граничный ввод;
* Ввод некорректных данных.

### [test_widget](tests/test_widget.py) для [widget](src/widget.py)
`mask_account_card` и `get_date`

Обработки виджетов:
* Автоопределение типа (карта/счет);
* Различные форматы и длины строк;
* Преобразование дат;
* Пустые строки и некорректный ввод.

### [test_processing](tests/test_processing.py) для [processing](src/processing.py)
`filter_by_state` и `sort_by_date`

Фильтрации и сортировки:
* Фильтрация по существующим и отсутствующим статусам;
* Сортировка по возрастанию и убыванию;
* Стабильность сортировки при дубликатах;
* Обработка пустых списков.

### [test_generators](tests/test_generators.py) для [generators](src/generators.py)
`filter_by_currency`, `transaction_descriptions` и `card_number_generator`

Работы генераторов с транзакциями:
* Проверка фильтрации по валюте, возврат пустого списка при отсутствии данных.
* Возврат корректных описаний операций, работа с пустым списком.
* Генерация номеров карт в заданном формате и диапазоне, граничные случаи.

### [test_decorators](tests/test_decorators.py) для [decorators](src/decorators.py)
`test_log_success_to_console`, `test_log_success_to_file`, `test_log_error_to_console` и `test_log_error_to_file`

Тесты логирования:
* Успешное выполнение функции (логируется сообщение "... ok");
* Возникновение исключения (логируется тип ошибки и входные параметры).

### [test_utils_and_external_api](tests/test_utils_and_external_api.py) для [utils](src/utils.py) & [external_api](src/external_api.py)
`test_load_transactions_success`, `test_load_file_not_found`, `test_load_invalid_json`, `test_load_not_a_list`,  
`test_convert_to_rub_already_rub`, `test_convert_to_rub_usd`, `test_load_csv` и `test_load_excel`

Конвертация валют:
* Логика работы без запроса к API, если валюта уже в рублях.
* Проверка конвертации USD/EUR -> RUB через обращение к внешнему API (APILayer).

Чтение и загрузка JSON, CSV, Excel:
* Успешная загрузка данных из файла.
* Обработка ошибок, если файл не найден или неверный формат.
* Проверка возврата пустого списка, если данные в файле — не список.

### [test_data_loader](tests/test_data_loader.py) для [data_loader](src/data_loader.py)
`test_load_csv`, `test_load_json`, `test_load_excel`, `test_empty_excel`, `test_corrupted_excel`,
`test_invalid_excel_structure`, `test_large_numbers_in_excel`, `test_missing_columns_excel`

Загрузка файлов:
* test_load_csv: Проверка корректной загрузки данных из CSV.
* test_load_json: Проверка корректной загрузки данных из JSON.
* test_load_excel: Проверка корректной загрузки данных из Excel (*.xlsx, *.xls).

Тесты на обработку ошибок и граничных случаев:
* test_empty_excel: Проверка возврата пустого списка из пустого файла.
* test_corrupted_excel: Проверка обработки невалидных (поврежденных) файлов Excel.
* test_invalid_excel_structure: Проверка обработки файлов с нестандартными колонками.
* test_large_numbers_in_excel: Проверка обработки очень больших чисел в ячейках.
* test_missing_columns_excel: Проверка обработки файлов с отсутствующими обязательными колонками.
